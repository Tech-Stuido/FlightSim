## 🔧 Assembly Instructions

### Step 1: Post-Processing
1. Remove all supports carefully with flush cutters
2. Sand contact points smooth (start 200 grit, finish 800 grit)
3. Clean parts with isopropyl alcohol
4. Dry fit all pieces before gluing

### Step 2: Painting Details
1. **Eyes:** Paint socket interior black, add red/orange gradient
2. **Energy Core:** Paint cavity silver, add orange translucent layer
3. **Panel Lines:** Use black wash to highlight seam lines
4. **Weathering:** Light dry brush silver on edges for wear

### Step 3: LED Installation (Optional)
1. Drill 5mm holes in eye sockets (back of head)
2. Route wires through neck cavity
3. Install LEDs in torso core cavity
4. Connect to battery pack hidden in base

### Step 4: Main Assembly
1. Attach legs to torso bottom using magnets
2. Insert brass pins into arm sockets for strength
3. Connect arms to shoulder joints
4. Glue neck peg into torso neck hole
5. Mount head onto neck peg

### Step 5: Hair Attachment
1. Align hair pegs with head mounting holes
2. Apply small amount of super glue to pegs
3. Press firmly and hold for 30 seconds
4. Ensure spikes are oriented correctly

### Step 6: Final Details
1. Install clear plastic eye lenses
2. Add energy core cover (clear filament print)
3. Touch up any visible seams with filler
4. Apply matte clear coat for uniform finish

## ⚠️ Troubleshooting

| Issue | Solution |
|-------|----------|
| Warping on feet | Increase bed temp to 65°C, use brim |
| Stringing on spikes | Retraction 6mm, reduce temp to 195°C |
| Layer shifting | Tighten belts, reduce speed |
| Poor adhesion | Clean bed, add glue stick layer |
| Support marks | Use tree supports, sand carefully |

## 💡 Tips for Best Results

1. Print the head vertically for best face quality
2. Use silk gold filament for authentic metallic shine
3. Print hair separately for easier support removal
4. Test fit joints before final assembly
5. Consider printing a display base with wiring channel
